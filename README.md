# 🏫 Шкільна платформа уроків та завдань (6-9 класи)

Інтерактивна веб-платформа для проведення уроків математики та інформатики, виконання практичних завдань та онлайн-моніторингу присутності й успішності учнів у реальному часі вчителем з можливістю фільтрації за класами (6-А, 6-Б, 7-А, 7-Б, 8-А, 8-Б, 9-А, 9-Б).

---

## 🌟 Основні можливості

### 1. 🎒 Для учнів
- **Швидкий вхід без складної реєстрації:** введення імені, вибір класу (6, 7, 8, 9) та літери класу (А, Б).
- **Зручна ієрархія:** вибір класу → предмета (Математика, Інформатика) → теми (кабінету).
- **Кабінет 8 класу: Інформатика — «Архіви даних. Стиснення даних» (`info-8-compress`):**
  - **Інтерактивний переглядач слайдів (12 слайдів):** зручний перегляд презентації уроку з навігацією та завантаженням оригінального файлу `.pptx`.
  - **Інтерактивна Лабораторія стиснення:**
    * *Експеримент 1 (Архівування тексту без втрат):* дослідження `archive_lesson1.txt` (420 КБ), `franko-...docx` (24 КБ), JPEG у ZIP; розрахунок розміру архіву, відсотка економії та коефіцієнта стиснення $K = \frac{S_{поч}}{S_{арх}}$ ($K \approx 327\times$ для тексту).
    * *Експеримент 2 (Візуальне стиснення фотографії з втратами):* порівняння якості зображення `vecteezy_...jpeg` (11.7 МБ) при різному ступені стиснення (100%, 15%, 1%), наочний показ пікселізації та артефактів JPEG, розрахунок коефіцієнта $K \approx 10\times$ та $K \approx 195\times$.
  - **10 покрокових практичних і тестових завдань:** з миттєвою перевіркою, підказками, вибором варіантів або введенням коефіцієнтів.
- **Кабінет 8 класу: Інформатика — «Операції з архівами» (`info-8-archive-operations`):**
  - Практична робота у системному застосунку «Файли» на Chromebook.
  - Завантаження TXT, DOCX і JPEG; створення трьох окремих ZIP-архівів та одного спільного.
  - Покрокові інструкції зі створення, перегляду вмісту й розпакування архівів.
  - Таблиця вимірювань із розрахунком економії та коефіцієнта стиснення.
  - 8 перевірочних завдань із підказками.
- **Кабінет 9 класу: Інформатика — «Формати файлів текстових документів. Режими роботи в середовищі текстового процесора» (`info-9-formats`):**
  - 13 навчальних слайдів і завантаження оригінальної презентації `.pptx`.
  - Завантаження документа `тексти з малюнками.docx` для практичної роботи.
  - Покроковий план імпорту в Google Docs та експорту у `.txt`, `.odt`, `.docx`, `.pdf`, `.rtf`.
  - Форма введення, порівняння й локального збереження виміряних розмірів п’яти файлів.
  - Посилання на спільний Google Документ, пояснення режимів роботи, прав доступу, коментарів та історії версій.
- **27 інтерактивних кабінетів з математики 6 класу (всього 529 завдань):**
  - *Складання цілих чисел:* Кабінети 1, 2, 3 (`math-6-add`, `math-6-add-2`, `math-6-add-3`)
  - *Віднімання цілих чисел:* Кабінети 1, 2, 3 (`math-6-sub`, `math-6-sub-2`, `math-6-sub-3`)
  - *Складання і віднімання цілих чисел:* Кабінети 1, 2, 3 (`math-6-mixed`, `math-6-mixed-2`, `math-6-mixed-3`)
  - *Множення цілих чисел:* Кабінети 1, 2 (`math-6-mul-1`, `math-6-mul-2`)
  - *Ділення цілих чисел:* Кабінети 1, 2 (`math-6-div-1`, `math-6-div-2`)
  - *Знаходження модуля числа:* Кабінет (`math-6-abs`)
  - *Знаходження протилежного числа:* Кабінет (`math-6-opp`)
  - *Коефіцієнт виразу, розкриття дужок, зведення подібних доданків*
  - *Ознаки подільності, прості множники, НСД та НСК*
  - *Підсумкові контрольні роботи №1 та №2*
  - *Звичайні дроби. Самостійна робота номер 1:* (`math-6-fractions-sr1`, 25 завдань — від'ємний степінь як дріб з віртуальною клавіатурою, порівняння дробів з однаковими знаменниками й чисельниками, вибір правильних і неправильних дробів)
  - *Звичайні дроби. Самостійна робота номер 2:* (`math-6-fractions-sr2`, 20 завдань — дроби, рівні 1, 2, 3, 4, та перетворення неправильних дробів у мішані числа з подвійним полем вводу й віртуальною клавіатурою)
  - *Звичайні дроби. Самостійна робота номер 3. Десяткові дроби:* (`math-6-fractions-sr3`, 20 завдань — перетворення звичайних дробів зі знаменниками 10, 100, 1000... у десяткові та навпаки)
  - *Звичайні дроби. Складання і віднімання:* (`math-6-fractions-add-sub`, 20 завдань — додавання та віднімання правильних і мішаних дробів з гарантовано додатним результатом)
- **Миттєва перевірка з підказками:**
  - При невірній відповіді блок підсвічується червоним із текстом підказки.
  - **Правильна відповідь учню не показується** — учень має можливість самостійно подумати та виправити відповідь.
- **Мобільна адаптація:** оптимізований інтерфейс для смартфонів, сенсорна клавіатура для математики та зручні картки варіантів для тестів.

### 2. 👩‍🏫 Для вчителів (Кабінет моніторингу)
- **Захищений вхід:** за паролем (за замовчуванням `123456`, можна налаштувати).
- **Фільтрація за класом:** можливість відобразити лише учнів конкретного класу (наприклад, 6-А, 6-Б, 8-А, 8-Б).
- **Живий моніторинг присутності в реальному часі:**
  - 🟢 **Онлайн (активний):** учень зараз працює безпосередньо на сторінці із завданнями.
  - 🟡 **Згорнув вкладку / відволікся:** фіксація перемикання на інші вкладки/додатки із зазначенням часу бездіяльності (Page Visibility API + Heartbeat).
  - ⚪ **Офлайн:** учень закрив сторінку.
- **Матриця завдань для кожного учня:** кольорова індикація розв'язаних завдань (зелений), помилок (червоний) та поточного завдання.
- **Детальний звіт по учню:** історія кожної спроби, введені відповіді, помилки та часові мітки.
- **Генерація посилання для учнів:** швидке копіювання посилання на кабінет або коду кімнати для поширення у класі.

## 🗄️ База даних PostgreSQL

Платформа працює з базою даних PostgreSQL. Параметри за замовчуванням:
```bash
POSTGRES_USER=school
POSTGRES_PASSWORD=123456
POSTGRES_DB=school
POSTGRES_HOST=localhost
POSTGRES_PORT=5050
```

При запуску сервер автоматично створює всі необхідні таблиці та заповнює базу даних 300 перевіреними завданнями згідно з математичними обмеженнями (числа від -20 до 20, максимум одне двозначне число в парі, комбінації від'ємних і додатних чисел).

## 🚀 Як запустити проект

### 1. Запуск за допомогою скрипту
```bash
./run.sh
```

### 2. Запуск вручну
```bash
python3 main.py
```
Сервер буде доступний за адресою: **`http://localhost:8000`** або у вашій локальній мережі **`http://<IP_комп'ютера>:8000`**.

## 🌐 Робота через ngrok або локальну Wi-Fi мережу

### Через локальну Wi-Fi мережу:
1. Дізнайтеся вашу локальну IP-адресу (наприклад, `192.168.1.100`).
2. Учні на телефонах підключаються до тієї самої Wi-Fi мережі та відкривають:
   `http://192.168.1.100:8000`

### Через ngrok:
1. В окремому терміналі запустіть:
   ```bash
   ngrok http 8000
   ```
2. Надайте згенероване публічне посилання `https://xxxx.ngrok-free.app` учням.
